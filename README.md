## Projects worth clicking

- [**czech-tabloid-scraper**](https://github.com/koprjaa/czech-tabloid-scraper) — 2,400 headlines from 18 Czech news feeds in 14 seconds, stdlib + requests + rich
- [**chromadb-embedding-visualizer**](https://github.com/koprjaa/chromadb-embedding-visualizer) — 3D fly-through of ChromaDB vector stores. Next.js + Three.js frontend, FastAPI + UMAP + HDBSCAN backend
- [**email-verifier**](https://github.com/koprjaa/email-verifier) — async SMTP/DNS verification with catch-all detection and Czech-provider reputation logic
- [**vocative-generator**](https://github.com/koprjaa/vocative-generator) — scripts sklonuj.cz to batch-decline Czech first names, with adaptive concurrency and resumable checkpoints
- [**czech-surname-restorator**](https://github.com/koprjaa/czech-surname-restorator) — Ray-distributed diacritic restoration for legacy Czech datasets (`Dvorak` → `Dvořák`)
- [**rm1000i-tray**](https://github.com/koprjaa/rm1000i-tray) — tiny Windows menu-bar widget that reads live PSU power draw over USB HID
