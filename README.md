## Projects

**Tools and libraries**

- [theses-mcp](https://github.com/koprjaa/theses-mcp) gives an MCP client full text search over one million Czech university theses, with links to the PDF files.
- [csv-tools](https://github.com/koprjaa/csv-tools) merges, deduplicates, and reorders CSV files that start with `#` comment rows. Standard library only.
- [xml-combiner](https://github.com/koprjaa/xml-combiner) merges a directory of XML files into one and keeps the namespaces.
- [dq-skills](https://github.com/koprjaa/dq-skills) is a set of ten Claude Code skills that audit and clean data quality in any SQL database.

**Data extraction**

- [justice-scraper](https://github.com/koprjaa/justice-scraper) reads financial statements out of the Czech Justice Registry by company identifier.
- [protext-scraper](https://github.com/koprjaa/protext-scraper) enumerates a Czech press release archive over Tor and renews the circuit on every block.
- [czech-tabloid-scraper](https://github.com/koprjaa/czech-tabloid-scraper) collects 2,400 headlines from 18 Czech RSS feeds in about 14 seconds.
- [shoptet-scraper](https://github.com/koprjaa/shoptet-scraper) finds and parses the product feeds of a Shoptet online shop.
- [tulipa-app-scraper](https://github.com/koprjaa/tulipa-app-scraper) reads a Helios ERP B2B portal whose API was mapped with mitmproxy.

**Applied AI and language**

- [chromadb-embedding-visualizer](https://github.com/koprjaa/chromadb-embedding-visualizer) renders a ChromaDB vector store as a 3D point cloud. UMAP and HDBSCAN in Python, Three.js in the browser.
- [email-verifier](https://github.com/koprjaa/email-verifier) verifies addresses over real SMTP connections and detects catch-all domains.
- [vocative-generator](https://github.com/koprjaa/vocative-generator) converts Czech first names into the vocative case in bulk.
- [czech-surname-restorator](https://github.com/koprjaa/czech-surname-restorator) restores diacritics to Czech surnames in legacy datasets.

**Desktop**

- [rm1000i-tray](https://github.com/koprjaa/rm1000i-tray) reads live power draw from a Corsair power supply over USB HID and shows it in the Windows tray.
- [miner-widget-stats](https://github.com/koprjaa/miner-widget-stats) shows mining pool hashrate and sensor temperature in the macOS menu bar.
